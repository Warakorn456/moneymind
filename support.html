เกี่ยวกับแอป / About MoneyMind

MoneyMind เป็นแอปบันทึกและวางแผนการเงินส่วนตัว — บันทึกรายรับ-รายจ่าย ตั้งเป้าหมายการออม ติดตามหนี้สิน คำนวณสินเชื่อ/ภาษี ดูพอร์ตการลงทุน และมีผู้ช่วย AI สำหรับสแกนใบเสร็จและให้คำแนะนำ ข้อมูลทั้งหมดเป็นการบันทึกด้วยตัวคุณเอง แอปไม่เชื่อมต่อบัญชีธนาคารและไม่ทำธุรกรรมการเงินใดๆ

MoneyMind is a personal finance tracker & budgeting tool. All data is entered manually by you; the app does not connect to bank accounts or process any financial transactions.

คำถามที่พบบ่อย / FAQ

การใช้งานฟีเจอร์ AI (Gemini)

ฟีเจอร์ AI (สแกนใบเสร็จ, ผู้ช่วยมายา) ใช้ Google Gemini คุณสามารถใส่ Gemini API Key ของตัวเองได้ฟรีที่ ตั้งค่า → Google Gemini API Key — ขอ Key ฟรีได้ที่ aistudio.google.com → Get API Key

ลืมรหัสผ่าน

ที่หน้าเข้าสู่ระบบ แตะ "ลืมรหัสผ่าน? รีเซ็ตรหัสผ่าน" แล้วกรอกอีเมลของคุณ ระบบจะส่งลิงก์รีเซ็ตให้ทางอีเมล

ซิงค์ข้อมูลข้ามอุปกรณ์

เข้าสู่ระบบด้วยอีเมลเดียวกันในทุกอุปกรณ์ ข้อมูลจะซิงค์อัตโนมัติผ่าน Firebase Cloud (ตรวจสอบได้ที่ ตั้งค่า → Firebase Cloud Sync)

ความเป็นส่วนตัวของข้อมูล

ข้อมูลการเงินของคุณถูกเก็บแบบเข้ารหัสและเข้าถึงได้เฉพาะบัญชีของคุณเท่านั้น อ่านนโยบายความเป็นส่วนตัวได้ที่ แอป → นโยบายความเป็นส่วนตัว

ลบบัญชี / ข้อมูล

ลบข้อมูลทั้งหมดได้ที่ ตั้งค่า → จัดการข้อมูล → ล้างข้อมูลทั้งหมด หากต้องการลบบัญชีถาวร ส่งอีเมลแจ้งเราได้ที่ที่อยู่ด้านบน
